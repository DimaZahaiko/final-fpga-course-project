# Курсовий проєкт: частотомір на Verilog у системі з MicroBlaze

**Регістри.**

|Зсув|Назва|Доступ|Значення|
|-|-|-|-|
|0x00|`WINDOW`|запис/читання|Тривалість вікна в тактах, \[31:0].|
|0x04|`CTRL`|запис|Запис 1 у розряд \[0] запускає вимірювання.|
|0x08|`COUNT`|читання|Кількість фронтів за останнє завершене вікно, \[31:0].|
|0x0C|`STATUS`|читання|Розряд \[0]: 1 вимірювання завершене, `COUNT` дійсний.|

**Верифікація.** Тестбенч сам генерує `sig\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\\_in` (цикл із затримками) і перевіряє `COUNT` для таких режимів:

1. Період сигналу 100 тактів, вікно 1000 тактів.
2. Період 40 тактів, вікно 2000 тактів.
3. Період 100 тактів, вікно 250 тактів. Для йього варіанту, множина допустимих значень (2; 3). Оскільки вхідний сигнал не синфазний до тактового сигналу, кількість виміряних фронтів залежить від фази вхідного сигналу на початку вимірювання.
